# 竹東出發七日旅遊

2026/9/16–9/22 從新竹縣竹東鎮出發，依序前往嘉義、旗山、台東、花蓮與羅東，最後返回竹東的七天六夜白牌機車旅遊 PWA。

## 每日住宿

- 9/16：嘉義
- 9/17：旗山
- 9/18、9/19：台東
- 9/20：花蓮
- 9/21：羅東
- 9/22：返回竹東

## 本機預覽

Service worker 需要 HTTP 環境，請在本目錄執行：

```powershell
python -m http.server 4173
```

開啟 `http://localhost:4173/`。直接雙擊 `index.html` 仍可查看與使用清單／預算，但不會啟用 PWA 離線快取。

行程包含分日停靠點、Google Maps 分段導航、住宿與美食建議、Open-Meteo 沿途即時天氣與旅程日期預報、行前清單、每日記帳、JSON 備份及離線 PWA 支援。

## 後段分歧

- 南橫不通替代：9/18 從旗山改住枋寮，9/19 經台 9 線南迴到台東，取消花蓮休息日以維持原返抵日期。
- 蘇花返程：9/21 花蓮經蘇花到羅東，9/22 經北宜返回竹東。
- 中橫返程：台 8 線確認全線開放時，9/21 花蓮經太魯閣、大禹嶺與合歡山到埔里，9/22 經國姓、東勢、卓蘭與三灣返回竹東。
- 中橫遇封閉、施工管制、豪雨、落石或錯過放行時段時，切回蘇花方案，不走未確認道路。
